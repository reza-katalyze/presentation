Input format guide
  • Use TITLE:, SUBTITLE:, and CLIENT: at top level.
  • Separate slides using ---, then define each with SLIDE:.
  • Use sections: NARRATIVE:, BULLETS:, KPIS:, SERIES:, FLOW:.
  • Section entries use dash-prefixed lines, for example - Label|42.
  • Flow lines use arrows, for example - Data Sources->Decision Engine.
